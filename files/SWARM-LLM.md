# SWARM-LLM: Collaborative Inference for Edge-based Small Language Models
## Summary
Proposes SWARM-LLM, a routing and collaboration layer for managing a "swarm" of SLMs on edge devices. It allows these smaller models to collaborate to handle tasks that would otherwise require cloud-level LLM capacity.
## Analysis
Focuses on SLMs as a solution to edge compute constraints. The collaborative aspect (swarm) is an innovative approach to distributed intelligence, reducing dependency on cloud bandwidth and latency while maintaining robustness for small-scale applications.
