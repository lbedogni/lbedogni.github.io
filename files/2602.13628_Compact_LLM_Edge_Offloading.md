# Compact LLM Deployment and World Model Assisted Offloading in Mobile Edge Computing
- **arXiv ID:** 2602.13628
- **Date:** February 2026
- **Topic:** Distributed Edge Inference, LLM Compression, MEC Offloading

## Summary
Presents a two-part solution for LLMs at the edge:
1. **ECLD Framework:** Combines structured pruning, low-bit quantization, and knowledge distillation to create compact LLMs.
2. **World Model-PPO:** An offloading optimization algorithm that uses a learned recurrent world model to minimize long-term average inference latency.

## Key Results
- **Compression:** Reduced storage by 70-80% (e.g., Llama-3.1-8B from 15.3GB to 3.3GB).
- **Energy:** Up to 50% reduction in per-query energy consumption.
- **Latency:** Reduced average inference latency by 12-30%.
- **Convergence:** World model-PPO speeds up convergence by ~50%.

## Analysis
Directly hits the "Distributed Edge Inference" and "Edge Computing" intersection. The combination of extreme compression and intelligent, world-model-based offloading is a state-of-the-art approach to bringing large models to the edge.
