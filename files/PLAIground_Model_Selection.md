# PLAIground: SLO-Driven Runtime Model Selection for Compound AI Systems in the Edge-Cloud-Space Continuum

**Date Found:** 2026-06-24
**Source:** arXiv (Submitted 2026-06-12)
**Category:** Edge-Cloud Continuum / Model Orchestration

## Summary
PLAIground is a framework for runtime model selection in compound AI systems operating across the edge-cloud-space continuum. It uses Service Level Objectives (SLOs) to decide which model (or combination of models) to use for a given task at runtime.

## Key Contributions
- **Edge-Cloud-Space Continuum:** Extends the typical edge-cloud model to include space-based (satellite) nodes.
- **SLO-Driven Selection:** Uses performance targets (latency, accuracy) to guide the orchestration of AI models.
- **Compound AI Systems:** Focuses on systems that combine multiple models rather than a single monolithic one.

## Analysis
This paper provides a high-level orchestration perspective on **Distributed Edge Inference**. The inclusion of the "space" continuum is particularly interesting for distributed systems and suggests a very large-scale approach to edge computing.
