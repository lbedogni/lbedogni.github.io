# The Cognitive Firewall: Securing Browser Based AI Agents Against Indirect Prompt Injection Via Hybrid Edge Cloud Defense
**Date:** March 24, 2026
**Source:** arXiv

## Summary
The authors present the **Cognitive Firewall**, a hybrid edge-cloud defense mechanism designed to protect browser-based AI agents from indirect prompt injection (IPI). It uses a three-stage split architecture to provide semantic analysis while reducing latency and enhancing privacy.

## Analysis
This is a novel application of split computing for security. By partitioning the defense logic between the edge (for speed/privacy) and the cloud (for deep semantic analysis), it demonstrates how split computing can mitigate the inherent trade-offs in AI agent security.
