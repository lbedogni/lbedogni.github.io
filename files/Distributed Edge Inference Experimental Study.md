# Distributed Edge Inference: an Experimental Study on Multiview ...

## Summary
This research investigates the "compute continuum" by implementing a real-world multi-view detection model (MvDet) across distributed edge nodes.

## Core Contribution
- **Framework**: Uses the **FastFL C/C++ high-performance edge inference framework**.
- **Experimental Setup**: Evaluates how a multi-view detection model can be distributed across multiple edge devices to optimize inference.
- **Goal**: Testing the opportunities offered by the compute continuum for complex, distributed AI applications.

## Key Findings
- Provides an experimental baseline for how multiview models perform when distributed across the edge.
- Highlights the challenges of orchestrating inference across a heterogeneous compute continuum.
