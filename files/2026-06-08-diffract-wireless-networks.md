# DIFFRACT: Neuralized Utility Maximization for Wireless Networks by Differentiable Programming
**Authors:** Chee Wei Tan, Siya Chen
**Link:** https://arxiv.org/abs/2606.07114
**Date:** 2026-06-08

## Summary
DIFFRACT introduces a framework that combines deep learning with optimization for wireless network resource management. It uses differentiable programming to map iterative interference management algorithms into neural network architectures via algorithm unrolling.
- **Capability:** Supports distributed, end-to-end gradient-based learning at the network edge.
- **Application:** Real-time adaptation to interference in terrestrial and non-terrestrial (satellite) environments.

## Analysis & Relevance
Relevant to **IoT and Edge Computing**. The ability to perform distributed learning and optimization directly at the network edge for interference management is a key enabler for high-density IoT deployments and distributed inference.
