# [2603.14958] Lightweight User-Personalization Method for Closed Split Computing

**Date:** 2026-03-16
**Topic:** Split Computing / Personalization
**URL:** https://arxiv.org/abs/2603.14958

## Summary
Proposes **SALT (Split-Adaptive Lightweight Tuning)**, a framework for adaptation in "closed" Split Computing systems (where head/tail network parameters are inaccessible). It uses a compact client-side adapter to refine intermediate representations.

## Key Results
- **Accuracy:** Improved personalized accuracy on CIFAR-10 from 88.1% to 93.8%.
- **Efficiency:** Reduced training latency by >60% compared to conventional fine-tuning.
- **Robustness:** Maintained >90% accuracy under 75% packet loss and high noise (sigma=1.0).

## Analysis
This is particularly useful for real-world IoT deployments where the cloud-side (tail) model is proprietary or too large to modify. The use of a lightweight adapter on the edge side allows for personalization and robustness without increasing the communication payload.
