# InTec: integrated things-edge computing

**Source**: Springer / Computing
**URL**: https://link.springer.com/article/10.1007/s00607-024-01388-6
**Date**: 2024/2025

## Summary
InTec (Integrated Things-Edge Computing) is a framework designed to optimize the distribution of machine learning (ML) pipelines across a three-tier architecture: Things, Edge, and Cloud. It aims to solve latency and bandwidth constraints of traditional cloud-based ML by strategically distributing tasks to the point of data generation.

## Key Results
- **Response Time**: 81.56% reduction.
- **Network Traffic**: 10.92% decrease.
- **Throughput**: 9.82% improvement.
- **Energy Consumption**: 21.86% reduction at the edge and 25.83% reduction in the cloud.

## Analysis & Relevance
This paper is highly relevant to **Split Computing** and **Distributed Edge Inference**. It demonstrates that a fine-grained distribution of the ML pipeline (not just offloading) significantly improves energy efficiency and latency, especially for real-time applications like human motion detection.
