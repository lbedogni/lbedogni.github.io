# AVERY

**Summary:**
AVERY is an intent-driven adaptive split computing framework for **Vision-Language Models (VLMs)** in disaster response scenarios. It uses "embodied self-awareness" to adapt the split point based on the current network conditions (which are typically unstable in disaster zones) and the mission intent.

**Analysis:**
A practical application of **Split Computing** and **Distributed Edge Inference**. It shows how VLM inference, which is normally too heavy for the edge, can be made feasible through adaptive partitioning.
