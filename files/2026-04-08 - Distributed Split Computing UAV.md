# Distributed Split Computing Using Diffusive Metrics for UAV Swarms
- **Date**: April 8, 2026
- **Source**: arXiv
- **Topic**: UAV Swarms, Distributed Split Computing, Diffusive Metrics

## Summary
This work addresses the volatility of UAV swarms by proposing a **fully distributed, diffusive metric-based approach** for split computing. It introduces "aggregated gigaflops" as a metric to quantify the available computational capacity of the swarm, allowing for dynamic task offloading as the swarm topology and network conditions shift.

## Analysis
Most split computing research assumes a stable edge-cloud relationship. This paper pivots to a *peer-to-peer* distributed model where the "edge" is a moving swarm. The use of diffusive metrics to balance load across a dynamic network is a key contribution to the field of Distributed Edge Inference in highly mobile environments.
