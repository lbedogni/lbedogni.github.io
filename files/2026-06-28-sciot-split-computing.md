# SCIoT: Design and Evaluation of a Split Computing Framework for IoT

**Venue:** IEEE Xplore / Semantic Scholar
**Tags:** #SplitComputing #IoT #EdgeComputing #AdaptivePartitioning

## Summary
SCIoT is a framework designed for Split Computing in the Internet of Things (IoT). It addresses the trade-off between local computation on resource-constrained devices and offloading to powerful edge servers. The framework allows for **flexible and adaptive partitioning** of workloads, taking into account:
1. Resource availability on the device.
2. Fluctuating network performance.
3. Data sensitivity (privacy).

## Key Analysis
- **Innovation:** Unlike static split points, SCIoT's adaptive partitioning allows the system to shift the "split" based on current environment conditions, optimizing for either latency or energy.
- **Impact:** Enables more robust deployment of ML models in heterogeneous IoT environments where network and hardware conditions are unstable.
- **Relevance to Luca:** Core focus on Split Computing and IoT, providing a framework for adaptive workload distribution.
