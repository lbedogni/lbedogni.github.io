# EdgeFM: Efficient Edge Inference for Vision-Language Models
**arXiv ID:** 2604.27476
**Date:** April 2026
**Link:** https://arxiv.org/abs/2604.27476

## Summary
EdgeFM is a lightweight, agent-driven VLM/LLM inference framework designed for cross-platform industrial edge deployment. It addresses the constraints of deterministic low latency and resource limitations in industrial scenarios.

### Key Contributions:
- **Agent-Driven Optimization:** Uses AI agents to search and tune configurations for generating highly optimized low-level kernels, reducing reliance on proprietary, closed-source toolchains.
- **Modular Skill Library:** Encapsulates agent-tuned kernel optimizations as reusable skills.
- **Cross-Platform Support:** Natively supports x86 and NVIDIA Orin SoCs, and provides the first end-to-end VLA deployment on the Horizon Journey platform.
- **Performance:** achieves up to 1.49x speedup over TensorRT-Edge-LLM on NVIDIA Orin.

## Analysis
This paper is highly relevant to Distributed Edge Inference. The shift toward using agents to automate the optimization of low-level kernels is a significant trend that moves away from hardware lock-in.
