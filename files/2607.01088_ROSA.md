# ROSA: A Robotics Foundation Model Serving System for Robot Factories
**arXiv ID:** 2607.01088v1
**Date:** 2026-07-01

## Summary
ROSA is a serving system designed for Robotics Foundation Models (RFMs) in industrial settings. It moves away from the traditional "one robot, one model" edge-computing paradigm toward a **shared GPU-pool serving** architecture.

## Analysis
The system addresses the limitation of on-robot GPUs (power, memory, compute) by allowing a fleet of robots to access high-performance server-class GPUs over the network. It introduces a robotics-aware abstraction for multi-model pipelines and a scheduler that optimizes for factory productivity (SLO-qualified) rather than just individual request latency.

## Key Results
- **Productivity:** Up to 12.06x improvement in factory productivity compared to conventional dedicated serving systems.
- **Infrastructure:** Built on Ray Serve with vLLM, PyTorch, and JAX backends.
- **Performance:** Improved battery duration and GPU utilization across the robot fleet.

## Relevance to Luca's Field
Highly relevant to **Distributed Edge Inference** and **Edge Computing**. It explores the trade-off between local (on-robot) and distributed (GPU pool) inference, providing a concrete implementation of a distributed inference system for complex, real-time robotics tasks.
