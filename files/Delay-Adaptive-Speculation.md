# Delay-Adaptive Speculation Control for Low-Latency Edge-Cloud LLM Inference

## Abstract
Speculative decoding (SD) accelerates LLM inference by using a lightweight draft model to propose tokens and a larger target model to verify them in parallel. In distributed edge-cloud inference, however, draft length must be adaptive to network latency to effectively leverage the cloud's capacity.

## Analysis
This research targets the latency-critical domain of LLM inference in edge-cloud systems. By making speculation control adaptive to delays, the proposed system optimizes for real-time performance, allowing the cloud to assist more effectively without the bottleneck of high network latency, which is a major hurdle in distributed edge inference.
