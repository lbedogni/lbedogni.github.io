# Optimized Split Computing Framework for Edge and Core Devices

**Date:** 2025-09-07
**URL:** https://arxiv.org/abs/2509.06049v1
**Field:** Split Computing, Edge Computing

## Summary
The paper presents an optimization framework for partitioning Feed-Forward Neural Network (FFNN) models across User Equipment (UE), edge nodes, and core nodes. The goal is to minimize the computational footprint on the UE while keeping total inference time within acceptable limits. The authors provide an efficient heuristic strategy to solve this partitioning problem in heterogeneous environments.

## Analysis & Key Results
- **Resource Reduction:** Reduces UE memory footprint by over 33.6% and CPU footprint by over 60%.
- **Versatility:** The framework is robust across heterogeneous settings and does not require model retraining.
- **Significance:** Focuses on the practical deployment of FFNNs on mobile devices by optimizing the split points across a multi-tier (UE-Edge-Core) architecture.
