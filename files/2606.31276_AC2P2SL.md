# AC²P²SL: Adaptive Communication-Computation Pipeline Parallel Split Learning over Edge Networks

- **arXiv ID:** 2606.31276
- **Date:** June 30, 2026
- **Field:** Split Learning, Edge Computing, Wireless Networks

## Summary
The paper addresses the latency bottleneck in Split Learning (SL) over wireless edge networks, where sequential computation and communication usually prolong training time. It proposes **AC²P²SL**, a framework that implements fine-grained pipeline parallelism across micro-batches to effectively overlap these processes between User Equipments (UEs) and the Base Station (BS).

## Key Contributions
- **Pipeline Parallelism:** Conceptualizes communication and computation as a unified pipeline to hide latency.
- **Joint Optimization:** Optimizes training time by considering communication, computation, storage constraints and UE heterogeneity.
- **Adaptive Re-allocation:** A strategy to maintain system resilience in dynamic wireless environments.

## Analysis
This is highly relevant to **Split Computing** and **Distributed Edge Inference**. The focus on overlapping communication and computation is a critical optimization for real-world deployment of split models where network jitter and UE heterogeneity are primary challenges.
