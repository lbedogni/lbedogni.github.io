# Semantic-aware Token Selection and Resource Optimization for Communication-efficient Split Federated Fine-tuning in Edge Intelligence

**Date:** 2026-06-08
**Field:** Split Computing, Federated Learning, Edge Intelligence

## Summary
This paper proposes a framework for communication-efficient Split Federated Fine-tuning (SFL) in edge intelligence. The core contribution is a semantic-aware token selection mechanism that reduces the amount of data exchanged between edge devices and the server during the fine-tuning of large Transformer-based vision models.

## Analysis
The work addresses a critical bottleneck in Edge AI: the communication cost of transferring intermediate activations (tensors) in split learning. By using semantic awareness to prune or select only the most informative tokens, the authors optimize resource utilization on mobile devices while maintaining model performance. This is highly relevant to Luca's interest in Split Computing and Distributed Edge Inference.
