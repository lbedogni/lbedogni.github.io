# Enabling Real-Time AI in O-RAN: Deploying and Measuring AI Inside a Near-RT RIC xApp

## Summary
This paper explores the deployment of AI models directly within the Near-Real-Time RAN Intelligent Controller (Near-RT RIC) of an O-RAN architecture. The authors implemented a network-state classification xApp using Logistic Regression (LR) and a shallow multilayer perceptron (MLP), exported as deterministic C modules to eliminate runtime dependencies. The study focuses on the feasibility of execution within the strict timing constraints of the Near-RT RIC (10 ms to 1 s).

**Key Results:**
- **Latency:** Inference latency was extremely low: 1-5 $\mu$s for LR and 10-25 $\mu$s for MLP.
- **End-to-End:** Total service latency remained below 4 ms, well within the 10 ms budget.
- **Accuracy:** Both models achieved similar accuracy (0.88-0.90).
- **Tooling:** Released "RIC Workbench" for reproducing the testbed.

## Analysis
This work is highly relevant to **Edge Computing** and **Distributed Inference**. While it doesn't explicitly implement "Split Computing" (partitioning a model across nodes), it demonstrates the "Edge Intelligence" paradigm by embedding the model as close to the data source (the RIC) as possible to minimize latency. It provides a practical benchmark for the timing requirements of AI at the network edge.

## Key Takeaways
- Deterministic C-based inference is critical for meeting hard real-time constraints in telecom infrastructure.
- Lightweight models (LR, shallow MLP) are sufficient for certain RAN state classification tasks and provide the necessary predictability.
