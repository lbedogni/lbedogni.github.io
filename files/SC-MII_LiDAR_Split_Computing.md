# SC-MII: Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing with Multiple Intermediate Outputs Integration
**Date:** January 11, 2026
**Source:** arXiv

## Summary
SC-MII proposes a system for 3D object detection using multiple infrastructure-based LiDARs. It leverages split computing to process local point clouds through initial DNN layers on edge devices and integrates multiple intermediate outputs to reduce power consumption and eliminate blind spots.

## Analysis
The focus here is on the integration of multiple "split" streams. Instead of a single point of failure or a single data source, SC-MII treats multiple edge nodes as distributed feature extractors, enhancing the robustness and coverage of 3D perception in smart cities/infrastructure.
