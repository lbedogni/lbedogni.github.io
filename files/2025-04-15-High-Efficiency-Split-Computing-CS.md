# High-Efficiency Split Computing for Cooperative Edge Systems: A Novel Compressed Sensing Bottleneck

**Date:** 2025-04-15
**URL:** https://arxiv.org/abs/2504.15295
**Field:** Split Computing, Compressed Sensing, Edge Inference

## Summary
This work introduces a novel split computing architecture based on compressed sensing (CS) theory to address bandwidth constraints and the accuracy-latency trade-off. The central component is the **High-Efficiency Compressed Sensing Bottleneck (HECS-B)**, which uses a compressed sensing autoencoder and knowledge distillation to create a bottleneck layer in the shallow part of a DNN. This allows for efficient compression of intermediate feature data transmitted from the edge to the cloud.

## Analysis & Key Results
- **Bandwidth Efficiency:** Reduces bandwidth utilization by 50%.
- **Computational Speed:** Achieves a 60% speed-up in computational efficiency.
- **Accuracy:** Maintains high accuracy despite significant compression.
- **Significance:** Bridges the gap between resource-constrained edge devices and intensive cloud services by optimizing the data transmission bottleneck via CS, which is a critical challenge in distributed inference.
