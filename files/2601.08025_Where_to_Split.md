# [2601.08025] Where to Split? A Pareto-Front Analysis of DNN Partitioning for Edge Inference

**Source**: arXiv ([Link](https://arxiv.org/abs/2601.08025))
**Date**: January 2026

## Summary
This paper addresses the challenge of deploying Deep Neural Networks (DNNs) on resource-constrained edge devices by reframing the DNN partitioning problem as a multi-objective optimization. Instead of focusing on a single metric (like latency), the authors argue that a trade-off between latency and throughput is critical, especially under varying network conditions.

## Key Contributions
- **ParetoPipe Framework**: An open-source tool for systematically identifying optimal partitioning strategies using Pareto front analysis.
- **Multi-Objective Optimization**: Moves beyond single-objective optimization to balance latency and throughput.
- **Heterogeneous Benchmarking**: Tested on a testbed of Raspberry Pis and a GPU-equipped edge server.
- **Toolchain**: Supports PyTorch RPC and a custom lightweight communication backend to minimize overhead.

## Analysis & Relevance
Highly relevant to **Distributed Edge Inference** and **Split Computing**. The focus on the latency-throughput trade-off is a practical improvement over previous "latency-only" models. The released framework `ParetoPipe` could be a valuable tool for benchmarking.
