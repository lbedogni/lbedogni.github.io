# Optimized Split Computing Framework for Edge and Core Devices
- **Source**: arXiv:2509.06049v1 (To appear on IEEE Transactions on Vehicular Technology)
- **Topic**: Split Computing / FFNN
- **Key Idea**: A framework to partition Feed-Forward Neural Network (FFNN) models across User Equipment (UE), edge nodes, and core nodes.
- **Results**: 
    - Reduces UE memory footprint by ~33.6%.
    - Reduces UE CPU footprint by ~60%.
    - Robust in heterogeneous settings without requiring retraining.
- **Significance**: Effective for resource-constrained UEs requiring high-quality user experience.
