# SC-MII: Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing (arXiv:2601.07119)

## Summary
The paper proposes **SC-MII**, a system for 3D object detection using infrastructure-based LiDARs. It employs a **Split Computing** approach where edge devices process local point clouds through initial DNN layers and transmit multiple intermediate outputs to an edge server. The server then integrates these features for final inference.

## Analysis
This paper directly applies **Distributed Edge Inference** to a concrete, high-demand use case: autonomous driving and infrastructure monitoring. By splitting the computation, it solves the "blind spot" problem of single LiDARs while keeping the compute load on edge devices low.

## Key Takeaways
- **Processing Gain**: 71.6% reduction in edge device processing time.
- **Latency**: Achieved a 2.19x speed-up.
- **Accuracy**: Minimal drop in accuracy (<1.09%) despite the split.
