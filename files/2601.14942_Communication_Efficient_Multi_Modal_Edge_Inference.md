# [2601.14942] Communication-Efficient Multi-Modal Edge Inference via Uncertainty-Aware Distributed Learning

**Date:** 2026-01-21
**Topic:** Distributed Edge Inference / Multi-Modal / Semantic Communication
**URL:** https://arxiv.org/abs/2601.14942

## Summary
A three-stage distributed learning framework for Multi-Modal Edge Inference (MMEI) over wireless links:
1. **Local SSL:** Devices learn shared/modality-specific encoders locally to save bandwidth.
2. **Evidential Fusion:** Centralized fusion calibrates uncertainty and aggregates features.
3. **Uncertainty-Guided Feedback:** Selective feature requests to optimize the communication-accuracy tradeoff.

## Key Results
- Attained higher accuracy with significantly fewer training communication rounds.
- Robust against modality degradation and channel variations.

## Analysis
Leverages the concept of "Semantic Communication" to ensure that only task-relevant meaning is transmitted. The uncertainty-aware feedback loop is a strong mechanism for managing the limited bandwidth of edge networks while maintaining high inference quality.
