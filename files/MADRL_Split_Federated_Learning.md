# MADRL-Based Collaborative Split Federated Learning

## Summary
This paper proposes a hierarchical framework for collaborative Split Federated Learning (SFL) involving Cloud, Edge, and Device layers. It utilizes Multi-Agent Deep Reinforcement Learning (MADRL) to optimize the complex interplay between model partitioning, aggregation control, and resource allocation.

## Key Contributions
- **MADRL Integration**: Employs multi-agent RL to handle the dynamic and stochastic nature of resource allocation and partitioning in a distributed setting.
- **Hybrid Paradigm**: Combines the privacy-preserving nature of Federated Learning with the computational efficiency of Split Learning.
- **Hierarchical Optimization**: Optimizes the flow of data and gradients across the Device $\rightarrow$ Edge $\rightarrow$ Cloud pipeline.

## Analysis
Relevant for **Split Computing** and **Distributed Edge Inference**. The integration of MADRL suggests a move toward autonomous, self-optimizing inference pipelines, which is a significant step forward for scalable edge AI.
