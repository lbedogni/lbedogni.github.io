# MTL-Split: Multi-Task Learning for Edge Devices using Split Computing

- **URL:** [https://arxiv.org/abs/2407.05982](https://arxiv.org/abs/2407.05982)
- **Date:** July 2024
- **Field:** Split Computing / Multi-Task Learning (MTL)

## Summary
MTL-Split explores how to partition a multi-tasking DNN within a split computing framework. It addresses the need for embedded systems (e.g., automotive) to run multiple inference tasks using a single shared DNN to save computing bandwidth.

## Analysis
This paper complements Ladon by focusing on the **partitioning strategy** for MTL-DNNs. It's essential for understanding how to optimize the split point when the model is serving multiple purposes, which is a common requirement in complex Edge Computing environments.
