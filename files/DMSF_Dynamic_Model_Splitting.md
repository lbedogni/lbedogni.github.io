# DMSF: A Dynamic Model Splitting Framework for Edge-Cloud Collaborative Inference
**URL:** https://ieeexplore.ieee.org/abstract/document/11432620
**Date Found:** 2026-07-11

## Summary
This paper proposes a **Dynamic Model Splitting Framework (DMSF)** designed for edge-cloud collaborative inference. The framework dynamically adjusts the split point of Deep Neural Networks (DNNs) to optimize for current network bandwidth and the available computational capacity of the edge device.

## Key Results
- **Memory Reduction:** Reduces memory overhead by 75%.
- **Latency:** Achieves 32.0% lower latency than existing methods.
- **Accuracy:** 12.2% higher perception accuracy.
- **Performance:** Millisecond-level switching between split points.
