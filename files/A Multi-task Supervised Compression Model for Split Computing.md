# A Multi-task Supervised Compression Model for Split Computing

## Summary
This paper focuses on improving the compression of intermediate features in split computing systems.

## Core Contribution
The authors propose a **Multi-task Supervised Compression Model**. 
- **Problem**: Most existing split computing compression models are task-specific, limiting their versatility across different applications.
- **Solution**: A supervised compression approach that leverages multi-task learning to create a more robust and generalized compression bottleneck.

## Key Findings
- Moves beyond task-specific assessments to a more generalized framework.
- Improves the efficiency of data transmission between the edge device and the server while maintaining performance across multiple tasks.

## Relevance
Relevant to **Split Computing** and **Distributed Edge Inference**, particularly in developing generalized compression layers that don't need to be retrained for every new task.
