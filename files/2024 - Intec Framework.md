# InTec: Integrated Things-Edge Computing: A Framework for Distributing Machine Learning Pipelines in Edge AI Systems

- **Title**: InTec: Integrated Things-Edge Computing: A Framework for Distributing Machine Learning Pipelines in Edge AI Systems
- **Authors**: (From Springer journal 'Computing', Published 2024/2025)
- **Link**: https://link.springer.com/article/10.1007/s00607-024-01388-6
- **Scout Date**: 2026-06-23

## Abstract
This paper introduces the **InTec (Integrated Things-Edge Computing)** framework, an innovative IoT architecture that leverages a three-tier setup (Things, Edge, and Cloud) to strategically distribute Machine Learning (ML) tasks. By processing data closer to the generation points, InTec aims to address critical bandwidth, latency, and energy constraints that traditional cloud-centric ML pipelines experience.

## Key Results & Evaluation
The framework was evaluated empirically using the **MHEALTH** dataset for human motion detection in smart homes. The results demonstrated substantial improvements:
- **Response Time**: 81.56% reduction
- **Network Traffic**: 10.92% decrease
- **Throughput**: 9.82% improvement
- **Edge Energy Consumption**: 21.86% reduction
- **Cloud Energy Consumption**: 25.83% reduction
