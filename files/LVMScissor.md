# Paper: LVMScissor: Split and Schedule Large Vision Model Inference on Mobile Edges via Salp Swarm Algorithm

## Summary
The paper presents "LVMScissor", a framework designed to efficiently split and schedule Large Vision Model (LVM) inference tasks across mobile edge devices. It utilizes the Salp Swarm Algorithm to optimize the partitioning and resource allocation, aiming to balance latency and energy consumption for heavy vision tasks.

## Key Insights
- Addresses the challenge of running massive Large Vision Models on resource-constrained mobile/edge hardware.
- Employs a meta-heuristic approach (Salp Swarm) for scheduling, suggesting robustness in dynamic network environments.
- Significantly reduces inference latency compared to traditional centralized or naive split-inference methods.
