# Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing with Multiple Intermediate Outputs Integration
- **arXiv ID:** 2601.07119
- **Date:** January 2026
- **Topic:** Split Computing, 3D Object Detection, Infrastructure LiDAR

## Summary
Introduces **SC-MII**, a system for 3D object detection in autonomous driving. It utilizes multiple infrastructure LiDARs and a Split Computing approach where edge devices process initial DNN layers and send intermediate outputs to a server for integration and final inference.

## Key Results
- **Latency:** 2.19x speed-up in inference.
- **Resource Load:** 71.6% reduction in edge device processing time.
- **Accuracy:** Minimal impact, with a maximum drop of 1.09%.

## Analysis
Shows a practical application of Split Computing for multi-sensor fusion at the edge. The "Multiple Intermediate outputs Integration" part is interesting as it suggests a more nuanced way of combining edge-processed features than simple concatenation.
