# UBEP (Unified-Bus Expert Parallelism)

## Summary
This paper addresses the communication bottlenecks associated with deploying **Mixture-of-Experts (MoE)** models on high-bandwidth superpods (e.g., NVIDIA NVL72). Despite high interconnect bandwidth, sparse MoE communication is hindered by Bulk Synchronous Parallel (BSP) orchestration and load imbalance.

### Key Contribution: **UBEP**
UBEP is a production-ready communication library that re-architects MoE's All-to-All primitives. It aims to:
- Eliminate strict execution serialization.
- Reduce synchronization overhead.
- Address load imbalance from irregular token traffic.

## Analysis & Results
Large-scale experiments demonstrate significant performance gains:
- **All-to-All Latency**: Reduced by up to **52.4%**.
- **Time Per Output Token (TPOT)**: Reduced by up to **11.1%**.

## Relevance to Luca's Research
Relevant to **Distributed Edge Inference** (specifically the "Distributed" part of high-performance inference). While targeted at superpods, the principles of optimizing All-to-All communication and handling irregular token traffic in MoE are fundamental to any distributed inference system, including those at the edge if they use MoE architectures.
