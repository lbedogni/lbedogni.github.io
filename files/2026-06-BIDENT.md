# BIDENT: Heterogeneous Operator-level Mapping for Efficient Edge Inference

**Submitted:** 3 June 2026
**Source:** arXiv

## Summary
BIDENT addresses the challenge of efficient inference on modern edge System-on-Chips (SoCs) that integrate heterogeneous processing units (PUs) such as CPUs, GPUs, and NPUs. Instead of relying on coarse-grained mapping, it proposes a heterogeneous operator-level mapping strategy to optimize the execution of AI models.

## Analysis
This paper is highly relevant to **Edge Computing** and **Edge Inference**. The key insight is that different operators within a neural network can be executed more efficiently on different PUs. By optimizing this mapping, BIDENT aims to maximize the utilization of available hardware and minimize latency, which is a core problem in deploying complex models on resource-constrained edge devices.
