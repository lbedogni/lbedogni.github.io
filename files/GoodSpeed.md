# GoodSpeed

**Summary:**
GoodSpeed focuses on **Distributed Edge Inference for LLMs**. It uses adaptive speculative decoding to optimize "fair goodput" (the rate of useful output) in resource-constrained environments, allowing lightweight draft models to accelerate the main model's inference across a distributed edge.

**Analysis:**
Combines **Distributed Edge Inference** with state-of-the-art LLM acceleration techniques. This is critical for bringing real-time LLM capabilities to the edge without relying entirely on a central cloud.
