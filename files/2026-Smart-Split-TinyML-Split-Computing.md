# Smart Split: Leveraging TinyML and Split Computing for Efficient Edge Inference

**Year:** ~2024-2026
**Source:** IEEE Xplore / ACM
**URL:** https://ieeexplore.ieee.org/document/10818181

## Summary
This research explores the integration of **TinyML** with **split computing** to implement machine learning in resource-constrained environments. Specifically, it focuses on a classification pipeline using an **ESP32 microcontroller** connected to a **Raspberry Pi** edge server.

## Key Findings
- **Performance Metrics:** Unlike many papers that focus solely on accuracy, this study emphasizes the **total time required for image capture and classification**.
- **Hardware Synergy:** Demonstrates a practical split between an ultra-low-power microcontroller (TinyML) and a more capable edge server.

## Analysis
This provides a practical benchmark for the "Split Computing" paradigm using common hardware (ESP32/Pi). It highlights the importance of end-to-end latency over theoretical model accuracy.
