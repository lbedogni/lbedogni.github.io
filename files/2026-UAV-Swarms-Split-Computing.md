# Distributed Split Computing Using Diffusive Metrics for UAV Swarms

**Date:** April 2026
**Keywords:** UAV Swarms, Distributed Split Computing, Diffusive Metrics, Dynamic Topology

## Summary
The paper introduces a fully distributed, diffusive metric-based approach for split computing in UAV swarms. It uses a new iterative measure called "aggregated gigaflops" to capture the computational capacity of each node and its neighbors, allowing the swarm to adaptively partition tasks as the topology shifts.

## Analysis
This is a strong example of **Distributed Edge Inference** applied to highly dynamic networks. The use of diffusive metrics suggests a decentralized control plane, which is essential for scalability and robustness in swarm robotics.
