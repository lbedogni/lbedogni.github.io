# LVMScissor: Split and Schedule Large Vision Model Inference on Mobile Edges via Salp Swarm Algorithm

**URL:** https://ieeexplore.ieee.org/document/10923690
**Date:** May 2025
**Category:** #LVM #SplitComputing #Optimization

## Summary
LVMScissor addresses the challenge of split inference for Large Vision Models (LVMs), where the size of intermediate data transferred between the edge and the server often becomes a bottleneck.

## Key Contribution
- **Model Parallelism:** Uses model parallelism to handle LVMs.
- **Salp Swarm Algorithm:** Employs a meta-heuristic algorithm to optimize the split point and the scheduling of tasks across the mobile edge.
- **Performance:** Reported to be faster than state-of-the-art inference acceleration methods.

## Analysis
The use of a meta-heuristic (Salp Swarm) for scheduling is an interesting approach to solve the NP-hard problem of optimal split point selection in dynamic network conditions.
