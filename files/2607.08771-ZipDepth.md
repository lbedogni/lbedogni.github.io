# ZipDepth

## Summary
ZipDepth is a lightweight monocular depth estimation network designed for deployment on embedded and mobile platforms. It addresses the gap between high-performance but computationally heavy foundation models and lightweight models that typically struggle with domain shift.

### Key Contributions:
- **Architecture**: Uses an efficient reparameterizable encoder-decoder.
- **Training**: Employs large-scale knowledge distillation from a foundation model over a diverse multi-domain training set.
- **Efficiency**: Only 6.1M parameters.
- **Performance**: Achieves real-time inference on power-constrained devices while maintaining zero-shot accuracy across five benchmarks.

## Analysis
ZipDepth is particularly relevant to Luca's research in **Edge Computing** and **Distributed Edge Inference**. By reducing the model size (50x smaller than foundation models) while preserving zero-shot capabilities, it demonstrates a viable path for deploying high-fidelity spatial awareness on IoT devices without requiring constant cloud offloading. This aligns with the goal of increasing autonomy and reducing latency at the edge.
