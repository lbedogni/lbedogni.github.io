# AI-embedded IoT healthcare optimization with trust-aware mobile edge computing

- **Venue:** Nature (Dec 2025)
- **Field:** IoT, Mobile Edge Computing (MEC), Security
- **Summary:** 
  Develops a trust-aware MEC framework for IoT-enabled healthcare. The model uses a combination of direct trust (interaction history) and indirect trust (neighbor feedback), augmented by a Random Forest classifier for anomaly detection. It also implements adaptive encryption strength based on the trust score.
- **Key Results:**
  - Enhances reliability of medical data transmission.
  - Effectively identifies and isolates malicious devices in the network.
  - Optimizes resource usage and latency for critical healthcare responses.
- **Analysis:** 
  The paper highlights the necessity of trust in distributed edge systems. The integration of temporal decay for trust scores ensures that the system adapts to the changing behavior of nodes in a dynamic IoT environment.
