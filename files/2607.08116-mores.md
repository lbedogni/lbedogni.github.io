# Mobile Reasoning-as-a-Service (MORES) via Distributed LLM Inference-Time Scaling
**arXiv ID:** 2607.08116
**Date:** 2026-07-09
**Category:** Distributed Edge Inference, Split Computing, LLMs

## Summary
The paper proposes **MORES**, a framework that enables "Reasoning-as-a-Service" by distributing the computational load of LLM inference-time scaling (specifically implicit reasoning) between edge devices and cloud servers.

### Key Contributions:
- **Distributed Implicit Reasoning:** Leverages the recursive structure of implicit reasoning (updating hidden states in latent space) to partition the computation. Edge devices can offload parts of these recursive updates to the cloud on demand.
- **Cooperative Inference:** Allows resource-constrained edge devices to access cloud computation to enhance reasoning capabilities without needing to increase the local model size.
- **Joint Optimization:** Formulates a joint computation and communication scheduling problem.
- **Semantic MoE-DRL:** Uses a semantic Mixture-of-Experts (MoE) based Deep Reinforcement Learning (DRL) algorithm to adaptively allocate resources (recurrent steps and transmission pruning rate) based on wireless conditions and task demands.

## Analysis
This paper directly addresses the "Split Computing" and "Distributed Edge Inference" interests of Luca. Instead of traditional split-inference (splitting a model's layers), it splits the *iterations* of a reasoning process. This is a novel take on inference-time scaling for the edge. The use of a semantic router for real-time expert selection in the DRL agent is a sophisticated way to handle heterogeneity.

**Potential Use-Cases:**
- Deploying complex reasoning agents on mobile devices.
- Dynamic offloading based on current network latency/bandwidth.
- Energy-efficient "thinking" on the edge.

**Verdict:** Must-read. Extremely relevant to the core research interests.
