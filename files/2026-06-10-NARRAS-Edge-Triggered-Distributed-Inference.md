# NARRAS: Edge-Triggered Distributed Inference for CSI-Based Localization in Vehicular IoT Networks

**Date:** 2026-06-10
**Authors:** Rodrigo Oliver, Ricardo Vazquez Alvarez, Alejandro Lancho, Stefano Rini
**Tags:** #IoT #VehicularNetworks #DistributedInference #Localization #EdgeComputing

## Summary
NARRAS addresses the resource trade-off in CSI-based localization using distributed antenna arrays. Instead of forwarding all observations to a fusion center (which is wasteful and bandwidth-heavy), it implements an edge-triggered mechanism to identify and forward only the most useful information.

## Analysis
This paper is highly relevant to Luca's interest in **Distributed Edge Inference** and **IoT**. It provides a practical application of distributed inference to solve a real-world localization problem in vehicular environments, specifically focusing on reducing communication overhead—a key challenge in edge computing.

## Key Takeaways
- Efficiently manages the communication-compute trade-off at the edge.
- Reduces uplink congestion in high-density vehicular IoT scenarios.
- Demonstrates the value of "triggered" or selective inference in distributed systems.
