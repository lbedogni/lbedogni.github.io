# Distributed Split Computing Using Diffusive Metrics for UAV Swarms

**Venue:** Journal of Systems Architecture (arXiv 2026)
**Tags:** #DistributedComputing #SplitComputing #UAV #EdgeInference

## Summary
This work introduces a fully distributed approach to split computing specifically for UAV swarms. To avoid the bottlenecks of centralized orchestration, it uses a diffusive metric called "aggregated gigaflops" to allow nodes to sense the compute capacity of their neighborhood. It also integrates an early-exit mechanism to adapt the inference path on-the-fly based on workload.

## Analysis
This is a prime example of "Distributed Edge Inference" in a highly dynamic topology. The shift from centralized to diffusive/distributed orchestration is a key advancement for scalability and reliability in aerial networks. The combination of split computing with early-exit mechanisms provides a multi-layered approach to efficiency.

**Key Takeaways:**
- Diffusive metrics replace global network knowledge.
- Early-exit mechanism for adaptive inference.
- Demonstrated improvements in latency and energy efficiency for UAVs.
