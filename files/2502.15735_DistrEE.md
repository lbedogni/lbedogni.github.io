# DistrEE: Distributed Early Exit of Deep Neural Network Inference on Edge Devices
**arXiv ID:** 2502.15735
**Date:** February 2025

## Summary
DistrEE is a distributed DNN inference framework designed for multi-node collaborative scenarios at the network edge. It aims to balance the trade-off between inference latency and accuracy.

## Key Contributions
- **Distributed Early Exit:** Integrates early exit mechanisms into distributed inference, allowing the model to terminate processing early if a satisfactory result is reached.
- **Early Exit Policy:** Implements a policy to control termination based on specific Quality of Service (QoS) requirements and available device resources.
- **Adaptive Inference:** Handles the fluctuating nature of edge device resources and varying input data complexity.

## Analysis & Relevance
This work aligns with **Distributed Edge Inference** and **IoT**. The "early exit" strategy is a key optimization for edge devices with limited power and compute, allowing them to save energy and reduce latency for simpler inputs while still leveraging the full network for complex ones.
