# Research Note: Blockchain-Assisted Edge Computing for IIoT

## Overview
A study from 2025 (Nature) proposing a private, blockchain-based architecture for Industrial Internet of Things (IIoT) to address security and scalability challenges.

## Key Insights
- Addresses centralization issues in traditional IIoT systems by shifting resources to the edge.
- Proposes a lightweight, private, decentralized, and scalable blockchain network.
- Uses Proof of Authority-based (PoAh) consensus to ensure only authenticated devices participate.
- Integrates asymmetric cryptography via virtual machines for secure, real-time data sharing and device authentication.

## Relevance
Highly relevant to edge computing and IoT infrastructure security.
