# Efficient CPU-GPU Collaborative Inference for MoE-based LLMs on Memory-Limited Systems
**arXiv:** 2512.16473
**Venue:** ASP-DAC 2026

## Summary
This paper proposes a CPU-GPU collaborative inference framework for Mixture of Experts (MoE) models, which typically exceed the memory capacity of consumer-grade GPUs.

## Key Mechanisms
- **Expert Caching:** Implements a caching mechanism on the GPU to keep frequently used experts, reducing the need for constant data transfer from CPU.
- **CPU Offloading:** Offloads computations for cache misses to the CPU, utilizing multithreading optimizations to handle the load efficiently.

## Results
- Demonstrates significant performance improvements for single-request inference scenarios on consumer-grade systems by maximizing hardware utilization.

## Analysis
By treating the CPU as a first-class compute partner rather than just a storage depot for offloaded weights, this framework makes large MoE models viable on hardware that would otherwise be unable to run them.
