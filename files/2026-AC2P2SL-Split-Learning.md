# AC$^2$P$^2$SL: Adaptive Communication-Computation Pipeline Parallel Split Learning over Edge Networks

**Status:** To Read
**Date Found:** 2026-07-01
**Field:** Split Computing / Split Learning / Edge Networks

## Abstract
In wireless edge networks, split learning (SL) enables a base station (BS) to utilize distributed data and computing resources. This paper proposes AC$^2$P$^2$SL, an adaptive communication-computation pipeline parallel framework for split learning, aiming to overlap the computation and communication phases to maximize throughput and minimize latency.

## Initial Analysis
A core "Split Computing" paper. It focuses on the *pipeline* aspect of Split Learning, which is often the bottleneck in real-world edge deployments. The focus on "Adaptive Communication-Computation" is highly relevant to the efficiency goals of Split Computing.
