# GOODSPEED: Optimizing Fair Goodput with Adaptive Speculative Decoding in Distributed Edge Inference

- **Venue:** IEEE INFOCOM 2026
- **Field:** Distributed Edge Inference, LLMs
- **Summary:** 
  Introduces a distributed speculative decoding framework designed for LLM inference at the edge. The system utilizes heterogeneous draft servers that collaborate with a central verification server to optimize "goodput" (the rate of correctly predicted tokens).
- **Key Results:**
  - Achieves higher goodput and lower latency compared to traditional inference.
  - Ensures fairness across different edge nodes.
  - Demonstrates performance gains on Qwen and Llama models.
- **Analysis:** 
  This paper is significant for distributed inference as it applies the concept of speculative decoding—typically a single-device optimization—to a distributed edge environment. It effectively manages the trade-off between local draft generation and central verification.
