# EdgeShard: Efficient LLM Inference via Collaborative Edge Computing

- **Title:** EdgeShard: Efficient LLM Inference via Collaborative Edge Computing
- **Field:** Edge Computing, Distributed Edge Inference, IoT
- **Date Found:** June 23, 2026

## Summary & Analysis
EdgeShard addresses the challenges of deploying Large Language Models (LLMs) on resource-constrained IoT/Edge devices. Traditionally, LLMs are deployed on the cloud, causing issues with latency, bandwidth, and data privacy. 

This work introduces collaborative edge computing for LLM deployment by sharding the model across multiple edge nodes, enabling them to collaboratively run inference tasks without overloading individual devices or relying completely on cloud resources.

# IoT-Edge Splitting with Pruned Early-Exit CNNs for Adaptive Inference

- **Title:** IoT-Edge Splitting with Pruned Early-Exit CNNs for Adaptive Inference
- **Field:** Split Computing, Distributed Edge Inference, Edge Computing
- **Date Found:** June 23, 2026

## Summary & Analysis
This paper addresses the overhead and synchronization requirements of offloading and split computing under dynamic environments. The authors introduce a framework that automatically constructs highly adaptive inference platforms by combining network pruning, early exit mechanisms, and FPGA-based hardware acceleration. This multi-layered splitting approach allows flexible execution partitions between the IoT device and the edge server depending on current network conditions and hardware load constraints.
