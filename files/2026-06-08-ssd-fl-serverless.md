# Towards Serverless Semi-Decentralized Federated Learning with Heterogeneous Optimizers
**Authors:** Su Wang, Mung Chiang, H. Vincent Poor
**Link:** https://arxiv.org/abs/2606.06687
**Date:** 2026-06-08

## Summary
The paper proposes Serverless Semi-Decentralized Federated Learning (SSD-FL), which removes the need for persistent server infrastructure. It uses a one-time D2D initialization phase to form clusters, followed by fully serverless training.
- **Innovation:** Integrates device-specific ML optimizers with network graph-based regularization.
- **Results:** Improves convergence speeds and communication efficiency across various network graphs and datasets.

## Analysis & Relevance
Highly relevant to **Distributed Edge Inference**. Moving away from centralized servers in FL is a major step toward truly distributed edge intelligence. The focus on heterogeneous optimizers addresses the real-world variance in edge device capabilities.
