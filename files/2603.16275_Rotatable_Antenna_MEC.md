# Rotatable Antenna-Enabled Mobile Edge Computing
- **arXiv ID:** 2603.16275
- **Date:** March 2026
- **Topic:** Mobile Edge Computing (MEC), Wireless Optimization, Latency

## Summary
Investigates the use of **Rotatable Antennas (RA)** in MEC systems to proactively improve wireless channel conditions. The paper jointly optimizes computing resource allocation, receive beamforming, and RA deflection angles using an alternating optimization (AO) framework.

## Key Results
- **Latency:** Significantly reduces the maximum computation latency for latency-critical users compared to traditional fixed-antenna benchmarks.

## Analysis
While more focused on the physical/MAC layer, it's relevant to the broader goal of reducing end-to-end latency in Edge Computing by addressing the wireless bottleneck.
