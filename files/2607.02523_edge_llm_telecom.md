# [2607.02523] Edge-Deployable LLM Fine-Tuning on a Single GPU for Telecom Network Troubleshooting

**Field:** Edge Computing / LLM / Telecom IoT
**Date:** May 2026
**URL:** https://arxiv.org/abs/2607.02523

## Summary
Focuses on the practical constraints of deploying LLMs at telecom edge sites (power, cooling, space). It argues that single-GPU fine-tuning is a requirement for scalability in these environments. The paper provides a systematic GPU profiling study using the **Unsloth framework** on edge-class accelerators.

It analyzes the impact of:
- Maximum sequence length and GPU memory utilization.
- LoRA rank and generation count on training stability.
- KV cache usage and activation memory overhead.
- Architectural differences between reasoning and non-reasoning models during SFT and RFT.

## Key Results
- Establishes practical configuration guidelines for stable and resource-aware LLM fine-tuning in telecom edge environments.
- Demonstrates that reasoning models behave differently during fine-tuning due to chat template and reasoning tag structures.

## Analysis for Luca
This is highly relevant to the **Edge Computing** and **IoT** research. It bridges the gap between theoretical LLM capability and the "brutal" reality of edge hardware (limited power/cooling). The use of Unsloth for edge-class accelerators suggests a path for deploying specialized, fine-tuned models for specific industrial tasks (like network troubleshooting) without needing massive GPU clusters.
