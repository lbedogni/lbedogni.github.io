# Reinforcement Learning based collaborative DNN inference for edge computing

This paper proposes an efficient framework for collaborative edge AI. By deploying multiple collaborative models on edge devices and servers connected via wireless IoT links, they utilize Reinforcement Learning (RL) to adapt to system dynamics, optimizing inference performance.

## Key Takeaways
- RL-driven framework for collaborative Edge AI.
- Adaptive to system dynamics.
- Focuses on efficient model deployment over wireless IoT links.
