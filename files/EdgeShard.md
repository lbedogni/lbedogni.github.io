# EdgeShard

## Summary
**EdgeShard** focuses on moving Large Language Model (LLM) inference from the cloud to the edge. It utilizes collaborative edge computing to shard LLM weights/computations across edge devices, reducing latency, bandwidth costs, and privacy risks associated with cloud-based LLMs.

## Analysis & Relevance
Highly relevant for **Distributed Edge Inference**. As LLMs become central to IoT, the ability to partition these massive models across a heterogeneous edge fabric is a critical challenge.
