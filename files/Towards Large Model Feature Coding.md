# Towards Large Model Feature Coding

**Summary:**
This paper introduces **LaMoFCBench**, a feature dataset designed to evaluate feature coding for machines (FCM) across various split-computing settings. It explores how to efficiently extract and code intermediate features from large models to reduce communication overhead between the edge and the cloud.

**Analysis:**
This is highly relevant to Luca's interest in **Split Computing**. The focus on "Feature Coding" suggests a move towards standardizing how intermediate activations are compressed and transmitted, which is a critical bottleneck in distributed inference.
