# Paper: Adaptive VLM Split Computing through Embodied Self-Awareness for Efficient Disaster Response Systems (arXiv:2511.18151v3)

## Summary
The paper presents AVERY, an adaptive split computing framework for Vision-Language Models (VLMs) deployed on resource-constrained UAVs in disaster response scenarios. It uses a cognitive-inspired dual-stream split (context stream + insight stream).

## Analysis
- **Key Contribution:** Enables deploying large VLMs (like LISA-7B) on edge devices by dynamically managing network conditions and operator intent, navigating the accuracy-throughput trade-off.
- **Results:** Achieved 11.2% higher accuracy than raw image compression and 93.98% lower energy consumption than full-edge execution.
- **Relevance:** Excellent application of distributed inference in constrained environments with dynamic network conditions.
