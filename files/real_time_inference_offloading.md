# Towards Real-Time Inference Offloading with Distributed Edge Computing

**Source:** IEEE / ACM
**URL:** https://ieeexplore.ieee.org/document/10330751

## Summary
Proposes a framework and algorithms for offloading Deep Neural Network (DNN) inference tasks across a distributed edge environment. It combines edge computing with parallel computing to exploit available resources in IoT device clusters.

## Analysis
The paper emphasizes the importance of considering both computation and communication parallelism. The goal is to minimize the total execution time (latency) for inference tasks, which is a central challenge in distributed edge inference.
