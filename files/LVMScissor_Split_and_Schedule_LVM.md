# LVMScissor: Split and Schedule Large Vision Model Inference

## Metadata
- **Title:** LVMScissor: Split and Schedule Large Vision Model Inference on Mobile Edges via Salp Swarm Algorithm
- **Source:** IEEE Transactions on Mobile Computing
- **Date:** 2025
- **Field:** Split Computing, Mobile Edge, Large Vision Models (LVMs)

## Summary
LVMScissor focuses on the efficient execution of Large Vision Models (LVMs) on mobile edge devices. It employs a "split and schedule" strategy, partitioning the model and optimizing the execution schedule using the Salp Swarm Algorithm.

## Analysis
This paper represents the state-of-the-art in Split Computing, specifically applying it to Vision Models (LVMs) rather than just standard CNNs or LLMs. The use of a swarm intelligence algorithm (Salp Swarm) for scheduling suggests a focus on dynamic, resource-aware optimization in mobile environments.
