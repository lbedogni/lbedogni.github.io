# Distributed Split Computing Using Diffusive Metrics for UAV Swarms
**arXiv ID:** 2503.16146v3
**Date:** Apr 2026 (v3)
**Field:** Distributed Split Computing / UAV Swarms

## Summary
Introduces a fully distributed, diffusive metric-based approach for split computing in large-scale UAV swarms to overcome the bottlenecks of centralized orchestration.

## Key Contributions
- **Aggregated Gigaflops:** A new iterative measure that captures a node's capacity and its neighbors' capacity without needing global network knowledge.
- **Intelligent Forwarding:** Partial inferences are forwarded to underutilized nodes.
- **Early-Exit Mechanism:** Adapts the inference pathway on-the-fly to handle workload surges.

## Analysis
The move from centralized to distributed orchestration using local diffusive metrics is a significant step for scalability in highly dynamic environments like UAV swarms.
