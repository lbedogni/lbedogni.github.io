# A Multi-task Supervised Compression Model for Split Computing

- **Venue:** WACV 2025
- **Field:** Split Computing, Edge AI
- **Summary:** 
  Proposes a supervised compression model to mitigate the communication bottleneck in split computing. Split computing divides a DNN model between an edge device (sensor/mobile) and a server; the communication of intermediate tensors can be costly. This model compresses these tensors using a multi-task supervised approach.
- **Key Results:**
  - Reduces transmission time and energy consumption on resource-constrained devices.
  - Maintains high inference accuracy despite compression.
- **Analysis:** 
  The use of a multi-task supervised model suggests a more generalized compression strategy that can adapt to different layers or tasks within the same network, making it more versatile than task-specific compression.
