# Communication-Efficient Multi-Modal Edge Inference via Uncertainty-Aware Distributed Learning
**arXiv ID:** 2601.14942
**Date:** Jan 2026
**Field:** Multi-Modal Edge Inference / Semantic Communication

## Summary
Proposes a three-stage communication-aware distributed learning framework to improve training and inference efficiency for multi-modal edge inference (MMEI) over bandwidth-limited wireless links.

## Key Contributions
- **Three-Stage Framework:**
    1. Local multi-modal self-supervised learning (reduces device-server exchange).
    2. Distributed fine-tuning with centralized evidential fusion (calibrates uncertainty).
    3. Uncertainty-guided feedback mechanism (selectively requests features for uncertain samples).
- **Results:** Higher accuracy with fewer training rounds and robustness to channel variation.

## Analysis
The integration of "uncertainty-guided feedback" is a smart way to manage the communication-accuracy tradeoff, which is a central challenge in distributed edge inference.
