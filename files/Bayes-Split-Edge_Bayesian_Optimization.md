# Bayes-Split-Edge: Bayesian Optimization for Constrained Collaborative Inference in Wireless Edge Systems

- **URL**: https://arxiv.org/abs/2510.23503
- **Date**: Oct 2025
- **Key Concept**: Joint optimization of **transmission power** and **neural network split point** using Bayesian Optimization.
- **Analysis**:
    - Targets energy-constrained devices (e.g., AR/VR headsets).
    - Uses a hybrid acquisition function to balance utility, sample efficiency, and constraint violation.
    - Significant performance gain: 2.4x reduction in evaluation cost compared to standard BO.
    - Demonstrates a sample-efficient approach to split computing in wireless environments.
- **Tags**: #SplitComputing #EdgeComputing #BayesianOptimization #WirelessNetworks
