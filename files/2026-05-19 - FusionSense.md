# FusionSense: Tri-Stage Near-Sensor Learning for Runtime-Adaptive Multimodal Edge Intelligence
- **Date**: May 19, 2026
- **Source**: arXiv
- **Topic**: Near-Sensor Learning, Edge Intelligence, Split Computing

## Summary
FusionSense proposes a **tri-stage computation split** (near-sensor $\rightarrow$ edge $\rightarrow$ cloud) for multimodal sensor systems. The core goal is runtime adaptivity: the system dynamically decides what to compute and transmit at each stage to satisfy strict energy, latency, and reliability constraints.

## Analysis
This paper advances the "Edge Inference" concept by pushing the first stage of computation into the sensor itself (near-sensor learning). This drastically reduces the data bandwidth required for the subsequent edge and cloud stages, making it highly relevant for low-power, high-frequency multimodal sensing in IoT environments.
