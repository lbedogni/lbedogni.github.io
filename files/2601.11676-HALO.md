# HALO: Semantic-Aware Distributed LLM Inference in Lossy Edge Network
**arXiv:** 2601.11676
**Venue:** INFOCOM 2026

## Summary
HALO is a framework designed to optimize distributed LLM inference across multiple edge devices in unreliable (lossy) network conditions. It aims to reduce the waiting time caused by delayed packets in strict synchronization schemes.

## Key Mechanisms
1. **Semantic-Aware Predictor:** Assesses the significance of neuron groups before activation.
2. **Strategic Allocation:** Less critical neuron groups are allocated to unstable devices.
3. **Parallel Execution:** Overlaps neuron group loading with model inference.
4. **Load-Balancing Scheduler:** Manages heterogeneous resources across devices.

## Results
- Achieves 3.41x end-to-end speedup for LLaMA-series LLMs on a Raspberry Pi cluster under unreliable network conditions.
- Performance remains comparable to optimal (lossless) conditions.

## Analysis
HALO's approach of "relaxed synchronization" based on semantic importance is a clever way to handle the reality of edge networks, ensuring that the slowest/most unstable link doesn't bottleneck the entire inference process.
