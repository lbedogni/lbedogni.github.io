# Feature Compression for Machines with Range-Based Channel Truncation and Frame Packing

- **Venue**: Data Compression Conference (DCC) 2025 / arXiv:2512.11134
- **Date**: March 2025
- **Field**: Feature Compression / Standards / Split Computing

## Summary
This paper proposes an enhancement for the MPEG standard on Feature Compression for Machines (FCM). It introduces methods to optimize the compression of AI features sent between devices in a split computing architecture.

## Key Contributions
- **Range-Based Channel Truncation**: A method to discard less important feature channels based on their range, reducing data volume without significant accuracy loss.
- **Frame Packing**: Optimizes how multiple frames of features are packed into a bitstream to improve compression ratios.
- **Standardization**: Directly informs the development of the MPEG FCM standard for interoperable feature coding.

## Analysis
Standardization is the "final boss" of split computing. For split computing to work across different vendors, we need standard bitstreams for features. This work's focus on MPEG FCM ensures that the optimizations for feature compression are interoperable and efficient across different AI architectures.
