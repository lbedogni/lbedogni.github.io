# InTec: Integrated Things-Edge Computing

## Metadata
- **Title:** InTec: integrated things-edge computing: a framework for distributing machine learning pipelines in edge AI systems
- **Source:** Springer (Computing)
- **Date:** 2024/2025
- **Field:** Distributed Edge Inference, IoT, Edge AI

## Summary
The InTec framework introduces a three-tier architecture (Things $\rightarrow$ Edge $\rightarrow$ Cloud) to strategically distribute machine learning pipelines. By processing data at the point of generation (Things layer) and leveraging the Edge and Cloud layers for more complex tasks, it aims to overcome the latency and bandwidth constraints of traditional cloud-centric ML.

## Key Results
- **Response Time:** $\downarrow$ 81.56%
- **Network Traffic:** $\downarrow$ 10.92%
- **Throughput:** $\uparrow$ 9.82%
- **Edge Energy Consumption:** $\downarrow$ 21.86%
- **Cloud Energy Consumption:** $\downarrow$ 25.83%

## Analysis
InTec provides a concrete benchmark for scalable and energy-efficient IoT applications. Its success in reducing response time by over 80% highlights the effectiveness of a highly distributed pipeline compared to simple edge-cloud offloading.
