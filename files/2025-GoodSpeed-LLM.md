# GoodSpeed: Optimizing Fair Goodput with Adaptive Speculative Decoding in Distributed Edge Inference

**Date:** December 2025
**Keywords:** Distributed Edge Inference, LLM, Speculative Decoding, Fair Goodput

## Summary
GoodSpeed addresses the computational challenges of real-time LLM inference in multi-user edge environments. It employs adaptive speculative decoding, using lightweight draft models to accelerate generation while optimizing "fair goodput" to ensure balanced performance across multiple concurrent users.

## Analysis
This paper focuses on the throughput and fairness of **Distributed Edge Inference** for Large Language Models. The use of speculative decoding in a distributed setting is a critical optimization for reducing the latency of the autoregressive decoding process.
