# Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing (SC-MII)
**arXiv ID:** 2601.07119
**URL:** https://arxiv.org/abs/2601.07119
**Date:** January 2026

## Summary
Introduces **SC-MII**, a system for 3D object detection using infrastructure LiDAR. It employs a Split Computing approach where edge devices process local point clouds through initial DNN layers and transmit multiple intermediate outputs to an edge server for integrated final inference.

## Analysis
- **Core Innovation:** Integration of multiple intermediate outputs from multiple edge devices for 3D detection.
- **Key Results:**
    - 2.19x speed-up in overall inference.
    - 71.6% reduction in edge device processing time.
    - Minimal accuracy drop (max 1.09%).
- **Relevance:** Demonstrates the scalability and efficiency of Split Computing for high-bandwidth sensor data (LiDAR) in autonomous driving contexts.
