# Multi-modal Model Partition Strategy

## Summary
This research explores DNN model partition strategies specifically for multi-modal models in collaborative end-edge scenarios. It leverages the AI acceleration components of modern IoT devices to run tasks concurrently on the device and edge cloud.

## Analysis & Relevance
Relevant to **Distributed Edge Inference** and **IoT**. Multi-modal split computing is a logical progression for complex edge sensing environments.
