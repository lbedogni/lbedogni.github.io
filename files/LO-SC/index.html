LO-SC

Summary

LO-SC challenges the dependency of Split Computing on remote servers. While traditional SC splits workloads between edge and cloud to save resources, it introduces latency and reliability issues. Pure on-device deployment often sacrifices accuracy.

LO-SC proposes Local-Only Split Computing, applying the concepts of splitting a DNN but executing it entirely on the edge device.

Key Results

  • Maintains high accuracy and predictable latency.
  • Removes the need for a reliable network connection and expensive server infrastructure while still benefiting from the organizational efficiency of “split” architectures.

Relevance to Luca

Relevant for Edge Computing and Distributed Edge Inference, particularly for scenarios where privacy or network instability makes cloud-reliance impossible.
