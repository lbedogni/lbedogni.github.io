# Multi-SPIN: Multi-Access Speculative Inference for Cooperative Token Generation at the Edge

**Authors:** Haotian Zheng, Zhanwei Wang, Mingyao Cui, Chang Cai
**Date:** June 2026
**Topic:** Edge AI, Speculative Inference, LLMs

## Summary
Multi-SPIN focuses on accelerating Large Language Model (LLM) inference at the edge through cooperative token generation. It employs a multi-access speculative inference mechanism where multiple edge devices or a combination of edge and cloud resources collaboratively propose and verify tokens to reduce the overall latency of token generation.

## Analysis
Relevant to **Distributed Edge Inference**, specifically applying **Speculative Decoding** in a distributed manner. This represents a move toward more sophisticated "cooperative" inference rather than simple offloading.
