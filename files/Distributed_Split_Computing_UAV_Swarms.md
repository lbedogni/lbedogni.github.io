# Distributed Split Computing Using Diffusive Metrics for UAV Swarms
**Date:** April 8, 2026
**Summary:** The paper proposes a fully distributed, diffusive metric-based approach for split computing in UAV swarms. The goal is to maintain low latency and high reliability even as the swarm size grows or the topology changes rapidly.
**Analysis:** Directly addresses "Distributed Edge Inference" and "Split Computing" in a highly dynamic environment (UAV swarms). This provides a blueprint for scaling split computing to multi-node edge clusters rather than just a simple device-cloud pair.
