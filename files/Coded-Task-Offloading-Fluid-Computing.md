# Coded Task Offloading for Fluid Computing: A Privacy-Aware Approach under D2D Networks

**Authors:** Diego Cajaraville-Aboy, Manuel Fernández-Veiga, Ana Fernández-Vilas, Rebeca P. Díaz-Redondo
**Date:** Submitted 9 July, 2026
**Source:** arXiv

## Summary
The paper proposes a coded task offloading mechanism for "Fluid Computing," a paradigm where tasks can be dynamically distributed across a set of available resources. To address privacy concerns in Device-to-Device (D2D) networks, the authors use coding techniques to ensure that no single participating device has access to the full private data of the task owner, while still allowing the collaborative computation of the result.

## Analysis
Relevant to **IoT** and **Distributed Edge Inference**. The concept of "Fluid Computing" extends the idea of edge computing by making the resource pool more dynamic and peer-to-peer. The integration of privacy-preserving coding with task offloading is a critical area for adoption in sensitive IoT environments (e.g., health or industrial data).
