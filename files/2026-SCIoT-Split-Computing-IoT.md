# SCIoT: Design and Evaluation of a Split Computing Framework for Collaborative Inference in the IoT

**Authors:** Lamazzi, L., Wang, J.W., Franco, F., Bedogni, L.
**Year:** 2026
**Source:** 23rd IEEE Consumer Communications and Networking Conference (CCNC 2026)
**URL:** https://iris.unimore.it/handle/11380/1401417

## Summary
The paper introduces **SCIoT**, a framework for Split Computing in the IoT that addresses the limitations of static partitioning in collaborative inference. Instead of relying on fixed model architectures or theoretical network conditions, SCIoT enables **flexible and adaptive partitioning** across heterogeneous devices.

## Key Contributions
- **Adaptive Partitioning:** Accounts for real-time resource availability, fluctuating network performance, and data sensitivity.
- **Dynamic Policies:** Implements policies that balance the trade-off between latency, bandwidth usage, and privacy.
- **Experimental Validation:** Evaluated across representative scenarios, showing the ability to reconfigure computations adaptively while maintaining efficiency.

## Analysis
This work is highly relevant as it moves toward a "compute continuum" where the split point of a neural network can move based on the current environment. The inclusion of privacy-aware policies makes it particularly useful for sensitive IoT deployments.
