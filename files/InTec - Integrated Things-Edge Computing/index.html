InTec: Integrated Things-Edge Computing

Summary

InTec is a framework designed to optimize the distribution of machine learning pipelines across a three-tier architecture: Things, Edge, and Cloud. It aims to solve the latency and bandwidth bottlenecks associated with traditional cloud-centric ML frameworks.

Key Results

The framework was validated using the MHEALTH dataset for human motion detection, showing significant improvements:

  • Response Time: Reduced by 81.56%
  • Network Traffic: Decreased by 10.92%
  • Throughput: Improved by 9.82%
  • Edge Energy Consumption: Reduced by 21.86%
  • Cloud Energy Consumption: Reduced by 25.83%

Analysis

InTec effectively demonstrates that a granular distribution of ML tasks (moving some to the “Things” layer) can drastically reduce the load on the edge and cloud, enhancing both responsiveness and energy efficiency. This is particularly relevant for real-time IoT applications in healthcare and home automation.
