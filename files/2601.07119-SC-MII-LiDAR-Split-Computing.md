# SC-MII: Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing

**URL:** https://arxiv.org/abs/2601.07119
**Date:** 2026-01-12
**Tags:** #split-computing #lidar #3d-detection #edge-computing

## Summary
The paper proposes **SC-MII**, a system for 3D object detection using multiple infrastructure-mounted LiDARs. It employs a Split Computing architecture where edge devices perform the initial feature extraction from point clouds and send multiple intermediate outputs to an edge server. The server then integrates these features to complete the detection.

Results:
- **2.19x speed-up** in overall inference.
- **71.6% reduction** in edge device processing time.
- Minimal accuracy drop (<1.09%).

## Analysis
This work demonstrates the scalability of split computing when dealing with multi-modal or multi-source high-bandwidth data (LiDAR). By integrating intermediate outputs at the server, it effectively handles the "blind spot" problem of single LiDAR setups while offloading the bulk of the computation from the edge.

## Relevance to Research
Matches "Split Computing" and "Edge Computing", illustrating a high-impact use case in autonomous infrastructure/driving.
