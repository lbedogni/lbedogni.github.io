# [2511.18151] AVERY: Adaptive VLM Split Computing through Embodied Self-Awareness for Efficient Disaster Response Systems

**Date:** 2025-11-22 (revised 2026-03-28)
**Topic:** Split Computing / VLMs / UAVs
**URL:** https://arxiv.org/abs/2511.18151

## Summary
Presents **AVERY**, an adaptive split computing framework for Vision-Language Models (VLMs) on UAVs. It moves from depth-wise partitioning to a **functional dual-stream split**:
- **Context Stream:** High-frequency, low-resolution for real-time awareness.
- **Insight Stream:** Low-frequency, high-fidelity for deep analysis.
A self-aware controller dynamically selects compression models based on network and intent.

## Key Results
- **Accuracy:** 11.2% higher accuracy than raw image compression.
- **Energy:** 93.98% lower energy consumption than full-edge execution.

## Analysis
The "functional split" (context vs. insight) is a significant evolution in split computing, mirroring cognitive processes. This allows UAVs to maintain situational awareness while selectively performing expensive semantic reasoning, which is critical for disaster response.
