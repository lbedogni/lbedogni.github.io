# Distributed Inference Optimization for Large Language Model in Edge-Cloud Collaborative Networks

**Source:** IEEE Xplore
**URL:** https://ieeexplore.ieee.org/document/11160773

## Summary
Addresses the challenge of running Large Language Models (LLMs) on resource-constrained edge nodes. It proposes an optimization strategy for distributed inference within an edge-cloud collaborative network.

## Analysis
As LLMs grow, single-node edge inference becomes impossible. This work likely employs split computing or model partitioning to distribute the LLM load across multiple collaborative nodes, balancing the latency of communication with the compute capacity of the edge.
