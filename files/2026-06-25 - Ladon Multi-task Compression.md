# A Multi-task Supervised Compression Model for Split Computing (Ladon)
- **Source**: arXiv:2501.01420 (Accepted at WACV 2025)
- **Topic**: Split Computing / Multi-task Learning
- **Key Idea**: Introduces "Ladon", the first multi-task-head supervised compression model for multi-task split computing.
- **Results**:
    - Outperforms lightweight baselines on ILSVRC 2012, COCO 2017, and PASCAL VOC 2012.
    - Reduces end-to-end latency by up to 95.4%.
    - Reduces mobile device energy consumption by up to 88.2%.
- **Significance**: Solves the accuracy/latency degradation problem when applying split computing to multi-task problems.
