# SubEdge: A Subscriber-Centric Edge Computing Subsystem in 6G Networks for AI

- **arXiv ID:** 2606.30554
- **Date:** June 29, 2026
- **Field:** 6G, Edge Computing, AI-native Terminals

## Summary
SubEdge is a subsystem for 6G networks designed to provide per-subscriber edge compute resources for AI-native terminals (e.g., autonomous vehicles, smart glasses). It solves the problem of deploying individualized, manufacturer-specific models that cannot be shared across subscribers or run entirely on-board.

## Key Contributions
- **Computing Context:** A data structure binding the Subscription Permanent Identifier (SUPI) to specific inference containers and edge nodes.
- **Joint Migration:** A mobility-event-driven mechanism that migrates both the compute instance and the traffic-routing policy simultaneously when a user changes cells.
- **Integration:** Operates as an Application Function over existing NEF APIs without requiring 3GPP core modifications.

## Analysis
Relevant to **Edge Computing** and **Distributed Inference** from an infrastructure perspective. It focuses on the "tenant" or "subscriber" aspect of edge AI, ensuring that as a user moves, their specific model instance follows them to maintain low latency.
