# Now or Never: Continuous Surveillance AIoT System for Ephemeral Events in Intermittent Sensor Networks
**Date:** December 30, 2025
**Source:** arXiv

## Summary
This paper introduces an **Energy-aware Elastic Split Computing Algorithm** for AIoT systems monitoring rare, ephemeral events. It ensures continuous sensing by dynamically offloading tasks to energy-rich neighboring nodes in intermittent sensor networks.

## Analysis
The "elastic" nature of the proposed split computing is key. Unlike static splits, this approach adapts to the energy state of the network, transforming split computing into a collaborative, distributed resource-sharing problem. This is highly relevant for remote environment monitoring.
