# Now or Never: Continuous Surveillance AIoT System for Ephemeral Events in Intermittent Sensor Networks
**Date:** December 2025
**Authors:** Joonhee Lee, Kichang Lee, Jeonggil Ko

## Summary
The authors propose an "Energy-aware Elastic Split Computing Algorithm" for AIoT systems monitoring rare, ephemeral events (like fires or animal vocalizations). The system dynamically offloads tasks to energy-rich neighbors in an intermittent sensor network to ensure continuous sensing.

## Analysis
This work focuses on the "IoT" and "Distributed Edge" aspect. The "Elastic Split Computing" approach is particularly interesting as it considers the energy state of the network as a primary constraint for the split decision. It's a great example of how split computing enables "always-on" capabilities in energy-starved IoT environments.
