# Vision Token Manipulation Attacks on Cloud-Edge Inference of Large Vision-Language Models

**Authors:** Zikai Zhang, Rui Hu, Olivera Kotevska, Jiahao Xu
**Date:** July 2, 2026
**URL:** https://arxiv.org/abs/2607.02819
**Topic:** Cloud-Edge Inference, LVLMs, Security

## Summary
This paper explores the security vulnerabilities of splitting computation between edge devices and cloud servers for Large Vision-Language Models (LVLMs). It identifies a new attack surface: the communication link where intermediate vision tokens are transmitted. The authors introduce the Vision Token Manipulation (VTM-Attack) to demonstrate how these tokens can be manipulated in a black-box setting.

## Key Contribution
- Identification of a critical vulnerability in split-inference for LVLMs.
- Introduction of the VTM-Attack and analysis of its impact on model output.

## Notes
- Highly relevant for split computing security and distributed edge inference.
