# RISE: Relay Inference and Online Scheduling for Efficient Edge-Device Collaborative Diffusion Model Services
## Summary
Presents RISE, a framework for deploying text-to-image diffusion models in an edge-cloud/device continuum. It uses relay inference to balance the workload between local devices and edge nodes, utilizing online scheduling to manage heterogeneous latency and quality requirements.
## Analysis
Collaborative diffusion model serving is a sophisticated evolution of edge inference. By offloading parts of the denoising process to edge servers, it enables faster generation while maintaining quality, which is crucial for real-time mobile edge applications.
