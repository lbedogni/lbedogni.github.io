# Securing Autonomous Vehicle Systems via Twin-Aware Federated Reinforcement Learning
**arXiv ID:** 2607.08137
**Date:** 2026-07-09
**Category:** Federated Learning, Edge Security, Autonomous Vehicles

## Summary
Introduces **SAPP**, a defensive framework for Federated Reinforcement Learning (FRL) in safety-critical autonomous driving to mitigate poisoning attacks.

### Key Points:
- Integrates **Digital Twins** for rehearsal-based learning.
- Uses historical aggregated parameters and central gradients to filter out malicious updates.
- Provides theoretical convergence guarantees under attack.

## Analysis
Relevant to Distributed Edge Inference and IoT. While the focus is security, the use of Digital Twins and Federated RL is a key pattern in modern distributed edge systems.
