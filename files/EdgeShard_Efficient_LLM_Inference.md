# EdgeShard: Efficient LLM Inference via Collaborative Edge Computing

**URL:** https://ieeexplore.ieee.org/document/10818760
**Date:** 2024/2025
**Category:** #LLM #EdgeAI #CollaborativeComputing

## Summary
EdgeShard focuses on the deployment of Large Language Models (LLMs) in IoT systems. It leverages collaborative edge computing to move inference away from the cloud, addressing latency, bandwidth costs, and privacy concerns.

## Key Contribution
Collaborative inference allows multiple edge devices to share the computational burden of LLM inference, making it feasible for resource-constrained environments.
