# Distributed Split Computing Using Diffusive Metrics for UAV Swarms

**Summary:**
This paper addresses the challenge of split computing in dynamic UAV swarms. It proposes a **diffusive metric-based approach** to distribute computation across the swarm, using a new "aggregated gigaflops" measure to handle rapid topology shifts and resource fluctuations.

**Analysis:**
Highly relevant to **Distributed Edge Inference**. It moves beyond the simple "client-server" split and explores "peer-to-peer" distributed inference within a mobile swarm, which is a key evolution of edge computing.
