# FusionSense: Tri-Stage Near-Sensor Learning for Runtime-Adaptive Multimodal Edge Intelligence

**Authors:** Sanggeon Yun, Ryozo Masukawa, Minhyoung Na, et al.
**Date:** May 19, 2026
**Topic:** Multimodal Edge Intelligence, Near-Sensor Learning, Split Computing

## Summary
FusionSense is a fusion-aware intelligent sensing framework designed for energy-constrained autonomous edge systems. It addresses the inefficiency of either sending all data to the cloud or using isolated uni-modal filters. It employs a three-stage procedure to train lightweight near-sensor classifiers that adaptively decide what to compute and transmit based on cross-modal dependencies.

## Key Contribution
- A tri-stage near-sensor learning framework for multimodal data.
- Runtime-adaptive decision-making to optimize energy and latency in edge-cloud split scenarios.

## Notes
- Relevant for multimodal IoT systems and adaptive edge computing.
