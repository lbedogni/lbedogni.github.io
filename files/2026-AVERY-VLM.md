# AVERY: Intent-Driven Adaptive VLM Split Computing via Embodied Self-Awareness for Efficient Disaster Response Systems

**Date:** March 2026
**Keywords:** VLM, Split Computing, Disaster Response, Adaptive Inference

## Summary
AVERY is an intent-driven adaptive split computing framework for Vision-Language Models (VLMs) designed for disaster response. It uses "embodied self-awareness" to dynamically adjust the split point between the edge and cloud, ensuring functionality even under the low-bandwidth and unstable network conditions typical of disaster zones.

## Analysis
The application of **Split Computing** to Large Models (VLMs) shows the evolution of these techniques from simple CNNs to complex multimodal models. The "intent-driven" aspect suggests a higher-level semantic control of the inference process, which is a sophisticated approach to **Distributed Edge Inference**.
