# Lightweight User-Personalization Method for Closed Split Computing (SALT)
**arXiv ID:** 2603.14958
**Date:** Mar 2026
**Field:** Split Computing / Model Adaptation

## Summary
Proposes SALT (Split-Adaptive Lightweight Tuning), a framework for adapting "closed" split computing systems where model architectures are inaccessible.

## Key Contributions
- **Client-Side Adapter:** A compact adapter that refines intermediate representations from a frozen head network.
- **Versatility:** Supports user personalization, communication robustness, and privacy-aware inference without modifying the base head/tail networks.
- **Performance:** Improved personalized accuracy (88.1% -> 93.8%) and reduced training latency by >60%.

## Analysis
SALT solves a practical problem: how to adapt a split model when you can't change the core weights (closed system). The use of intermediate representation refinement is an efficient alternative to full fine-tuning.
