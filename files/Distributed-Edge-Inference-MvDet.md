# Distributed Edge Inference: an Experimental Study on Multiview Detection

**Source:** ACM Digital Library
**URL:** https://dl.acm.org/doi/10.1145/3603166.3632561

## Summary
This paper presents an experimental study on the "compute continuum" using a real-world multi-view detection model (**MvDet**). It utilizes the **FastFL C/C++ high-performance edge inference framework** to test the opportunities offered by distributed edge environments.

## Key Focus
- **Compute Continuum:** Investigates how to devise applications that effectively utilize the complex environment between edge and cloud.
- **Multiview Detection:** Implements a specialized model for detection across multiple views, distributing the inference load.

## Analysis
Relevant for its use of a high-performance C/C++ framework (FastFL), which is crucial for reducing overhead in distributed inference. It focuses on the architectural challenge of coordinating multiple views in a distributed manner.
