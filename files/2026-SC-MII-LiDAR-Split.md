# SC-MII: Infrastructure LiDAR-based 3D Object Detection on Edge Devices for Split Computing with Multiple Intermediate Outputs Integration
**Date:** 2026-01-11
**Source:** arXiv (Taisuke Noguchi et al.)

## Summary
SC-MII addresses the challenges of deploying state-of-the-art 3D object detection models on edge devices, specifically for autonomous driving. It leverages "Split Computing" and integrates data from multiple infrastructure-based LiDAR sensors to eliminate blind spots and reduce the computational burden on individual edge devices.

## Analysis
By shifting from single-device sensing to infrastructure-assisted split computing, the system can handle more complex models without overloading the vehicle's onboard hardware. The integration of multiple intermediate outputs allows for a more flexible split point.

## Key Results
- Overcame blind spots inherent in single LiDAR setups.
- Reduced local processing time and energy consumption on edge devices.
