# RISE: Relay Inference and Online Scheduling for Efficient Edge-Device Collaborative Diffusion Model Services

- **arXiv ID:** 2606.17378
- **Date:** June 16, 2026
- **Field:** Distributed Inference, Diffusion Models, Edge AI

## Summary
RISE optimizes the deployment of text-to-image diffusion models by splitting the denoising workload between an edge server (large model) and a user device (small model). It avoids the trade-off between high-fidelity/high-latency edge models and low-fidelity/low-latency device models.

## Key Contributions
- **Relay Inference:** A training-free mechanism where the edge model handles early denoising steps (semantic structure) and the device model handles final refinement (details).
- **Contextual Bandit Scheduler:** An online scheduler that selects the optimal relay configuration based on prompt complexity, user preference, and real-time network/node loads.
- **Efficiency:** Achieves up to 2.1x speedup while maintaining the quality of the full-sized model.

## Analysis
This is a prime example of **Split Computing** applied to generative AI. The "relay" approach—splitting the task by the *phase* of the algorithm (denoising steps) rather than just a layer split—is an interesting direction for collaborative inference.
