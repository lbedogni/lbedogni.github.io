# TEMPO: Tight Control of Haemophilia with Crowdsensing
*Date: 2022–2023*

## Summary
This project develops a crowdsensing platform for real-time haemophilia monitoring. By integrating wearable biosensors with patient-reported data, TEMPO predicts bleeding episodes with 89% accuracy using machine learning. A 6-month clinical trial showed a 34% reduction in bleeding incidents through proactive treatment adjustments.

## Key Contributions
- Created multidomain crowdsensing system combining wearable biosensors, patient logs, and treatment records
- Deployed ML models predicting bleeding episodes with 89% accuracy, enabling prophylactic interventions
- Demonstrated 34% reduction in bleeding episodes during clinical trial with 45 patients
